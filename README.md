# Thankful Mama Co — Meal Planner

A weekly dinner-planning tool: browse recipes by protein, pick what you're
making this week, and get a combined shopping list plus per-recipe Walmart
links to check out with.

Static HTML/CSS/JS, no build step — same pattern as The Cracks App and
Momma Money. Hosted on GitHub Pages.

## Status

**v1 (current):** Beef, Pork, Chicken — 29 recipes, pick-and-build-list flow,
Walmart click-through links.

**Coming:** Turkey, Seafood, Meatless/Pasta, Flex-Protein recipes; breakfast/
lunch/snacks; Kroger cart sync (real "add to cart" for Kroger-family stores,
via Kroger's public Cart API + a small Supabase backend to hold the OAuth
client secret); printable version of the recipe sheet.
